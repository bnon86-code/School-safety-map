# أمي تقول لي — برنامج الرفق

مشاركات أولياء الأمور لطالبات المدرسة المتوسطة الأولى والثانية بالخبر في برنامج الرفق، تحت شعار «رِفقٌ يجمعنا».

- `index.html` صفحة العرض: المقطع المرئي، وبطاقات الأمهات مع التكبير والعرض التلقائي على الشاشة.
- `cards/` بطاقات الأمهات (41 بطاقة).
- `media/` المقطع المرئي وصورته المصغّرة.
