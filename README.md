# خريطة السلامة المدرسية

خريطة تفاعلية ثلاثية الأبعاد للمتوسطة الأولى والثانية بالخبر (١٤٤٨هـ).

## المحتوى
- الدور الأرضي والدور الأول مع أسماء الغرف
- ٣٣ طفاية حريق بأرقامها وأنواعها (بودرة ABC صغيرة وكبيرة، CO2) وصندوق خرطوم الحريق
- مخارج الطوارئ والسلالم
- العدادات الكهربائية الخمسة
- نقاط التجمع الداخلية والخارجية
- محاكاة الإخلاء (حريق)، وحريق المختبر مع إغلاق الدرج الشرقي، والتهديد الجوي، مع سير الخطة وأدوار اللجنة
- تحديد موقع حريق افتراضي وإظهار أقرب الطفايات وأقرب مخرج
- تدريب تفاعلي على استخدام طفاية الحريق وأرقام الطوارئ
- لجنة الأمن والسلامة وأدوار المنسوبات

## التشغيل
افتحي `index.html` في المتصفح، أو فعّلي GitHub Pages من إعدادات المستودع (Settings ← Pages ← Branch: main).
